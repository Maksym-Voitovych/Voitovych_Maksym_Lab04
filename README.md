# Лабораторна робота №4: ООП, SOLID та статична типізація

**Тема:** Розширена об’єктно-орієнтована архітектура системи банківських рахунків (Варіант 4).

**Автор:** Войтович Максим Андрійович (група ФеП-31).

## Опис проєкту

Проєкт є продовженням системи банківських рахунків. Мета роботи — застосувати принципи SOLID, статичну типізацію Python (`mypy strict`) та патерни проєктування для створення надійної й гнучкої архітектури.

## Основні можливості

* **SOLID та багатошарова архітектура:** розділення моделей, репозиторіїв і бізнес-логіки.
* **Value Objects:** незмінні класи `Money` і `Transaction` із валідацією та підтримкою арифметики.
* **Protocol:** реалізація інтерфейсу `Notifier` для сповіщень.
* **Generics:** універсальний репозиторій `InMemoryRepository[T]`.
* **AccountCollection:** власна колекція з підтримкою ітерації, індексації та перевірки елементів.
* **total_ordering:** автоматичне створення операторів порівняння для `Money`.
* **Статична типізація:** перевірка коду за допомогою `mypy` у режимі `strict`.
